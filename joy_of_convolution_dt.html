Welcome! (narration as text)

Draft transcript of the original audio narration by Cherie Weinert. Not yet checked against the recording.

Welcome to the world of discrete-time, linear time-invariant systems. I will briefly describe the convolution representation of such systems and the use of the Java applet below. In the next audio clip, I will suggest a few exercises.

In a linear time-invariant system, the output signal y[n] is related to the input signal x[n] by the convolution summation. In this summation, h[n] is a signal that characterizes the behavior of the system. Indeed, it is easy to show that h[n] is the response of the system to the unit pulse input signal. The unit pulse signal, usually written δ[n], is the all-zero sequence, except that it has the value of 1 at n = 0.

To explore convolution using the applet, position the page so that all four layers of windows are visible. Select x[n] and h[n] from the provided signals, or use your mouse to sketch them. Then click on the first k-axis, where of course k is the summation index in the convolution expression. This displays the signals h[k] and x[n − k] in the summand, with the value of n set by your click. The corresponding product of signals in the summand and the resulting value of y[n] are displayed in the last two windows. As you drag the value of n with the mouse, the summand and the output signal are updated.

This is a good time to explore the applet.

The behavior of a linear, time-invariant discrete-time system with input signal x[n] and output signal y[n] is described by the convolution sum

y[n]= ∑k=−∞∞ h[k] x[n−k]

The signal h[n], assumed known, is the response of the system to a unit-pulse input.

The convolution summation has a simple graphical interpretation. First, plot h[k] and the "flipped and shifted" x[n - k] on the k axis, where n is fixed. Second, multiply the two signals to obtain a plot of the summand sequence indexed by k. Summing the values of this sequence with respect to k yields y[n]. These operations can be repeated for every value of n of interest.

To explore graphical convolution, select signals x[n] and h[n] from the provided examples below, or use the mouse to draw your own signals or to modify selected signals. Then click at a desired value of n on the first k axis. After a moment, h[k] and x[n - k] will appear. Drag the n symbol along the k axis to change the value of n. For each n, the corresponding summand h[k]x[n - k] and output value y[n] will be displayed in their respective windows.

Exercises. (narration as text)

Draft transcript of the original audio narration by Cherie Weinert. Not yet checked against the recording.

As a first exercise, verify with the applet that h[n] is the response of the system to a unit pulse input. This means that if we know the response of a linear time-invariant system to the unit pulse input, then we can use convolution to compute the response to any input signal.

Remember, you can pause or replay portions of this audio clip when convenient.

It is obvious that the convolution sum represents a linear system. However, it is worthwhile to experiment with various time shifts of a particular input signal in order to verify the property of time invariance.

A causal system is a system where the output signal at time n depends only on input signal values for times less than or equal to n. Verify that a causal system corresponds to a unit pulse response h[n] that is zero for negative values of n. For the remaining exercises, you might want to concentrate on causal systems.

The fourth exercise is to verify with examples that convolution is commutative. In other words, the output of a system with unit pulse response h[n] and input signal x[n] is the same as the output of a system with unit pulse response x[n] and input signal h[n].

Exercise 5 involves understanding how a linear time-invariant system can act as a low-pass filter. Draw the h[n] whose only nonzero values are the values ½ at n = 0 and n = 1. Then sketch input signals whose amplitudes oscillate rapidly and perform the convolutions. Notice that the output signals are diminished in amplitude and smoother than the input signals. The system filters out some of the high-frequency content in the input signal. As an extreme example, if you sketch an input signal that looks like (−1)n for positive values of n, the highest-frequency signal possible in discrete time, the output signal will be almost the zero signal.

The last exercise is to explore simple unit pulse responses for which the corresponding system acts as a high-pass filter. At the extreme, suppose the input signal is constant, say all ones, the lowest-frequency signal possible in discrete time. Then the response of your system should be almost the zero signal.

Quiz on Discrete-Time Convolution

A companion to Joy of Convolution (Discrete Time). It is recommended that you use the applet to explore the question, and then see if you can mathematically justify your conclusion.

  1. If x[n] and h[n] both are odd signals, that is, x[−n] = −x[n] and h[−n] = −h[n], then the output signal y[n] will be a
    • an even signal
    • an odd signal
    • such that y[0] = 0
    • none of the above
  2. If a discrete-time LTI system is such that the output signal is always identical to the input signal, then the unit-pulse response of the system is
    • a unit step
    • a unit pulse
    • all zeros
    • all ones
  3. If an LTI system has a unit-pulse response with a finite number of nonzero values, and the input signal has a finite number of nonzero values, then the output signal
    • is all zeros
    • is constant
    • has a finite number of nonzero values
    • none of the above
  4. If h[n] is a unit-step function and the input signal x[n] is a unit-ramp function, then the output signal value y[2] will be
    • 0
    • 1
    • 2
    • 3
    • none of the above
  5. Suppose h[n] is all zero except for h[0] = h[1] = h[2] = 1/3. The best description for this LTI system is that it is
    • a low-pass filter
    • a high-pass filter
    • a bandpass filter
    • an all-pass filter
