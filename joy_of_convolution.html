Welcome! (narration as text)

Draft transcript of the original audio narration by Cherie Weinert. Not yet checked against the recording.

Welcome to the world of continuous-time, linear time-invariant systems, and the convolution representation. I will briefly describe this representation and the use of the Java applet below.

For a linear time-invariant system, the output signal, y(t), is related to the input signal, x(t), by the convolution integral. The signal h(t) in the integrand characterizes the behavior of the system. As will be discussed later, h(t) is the system response to the unit impulse input signal.

To explore convolution using the applet, position the page so that all four layers of windows are visible. Select x(t) and h(t) from the provided signals, or use your mouse to sketch desired signals. Then click on the first v-axis, where v is the integration variable in the convolution expression. This displays the signals h(v) and x(t − v) in the integrand, with the value of t set by your click. The corresponding product of signals in the integrand, and the resulting value of y(t), are displayed in the last two windows. As you drag the value of t with the mouse, the integrand and the output signal are shown.

This is a good time to explore the applet. In the next audio link, I will provide a few exercises.

The behavior of a linear, continuous-time, time-invariant system with input signal x(t) and output signal y(t) is described by the convolution integral

y(t)= ∫−∞∞ h(v) x(t−v) dv

The signal h(t), assumed known, is the response of the system to a unit impulse input.

To compute the output y(t) at a specified t, first the integrand h(v)x(t - v) is computed as a function of v. Then integration with respect to v is performed, resulting in y(t).

These mathematical operations have simple graphical interpretations. First, plot h(v) and the "flipped and shifted" x(t - v) on the v axis, where t is fixed. Second, multiply the two signals and compute the signed area of the resulting function of v to obtain y(t). These operations can be repeated for every value of t of interest.

To explore graphical convolution, select signals x(t) and h(t) from the provided examples below, or use the mouse to draw your own signal or to modify a selected signal. Then click at a desired value of t on the first v axis. After a moment, h(v) and x(t - v) will appear. Drag the t symbol along the v axis to change the value of t. For each t, the corresponding integrand h(v)x(t - v) and the output value y(t) will be displayed in their respective windows.

Exercises (narration as text)

Draft transcript of the original audio narration by Cherie Weinert. Not yet checked against the recording.

As a first exercise, investigate the claim that h(t) is the response of the system to a unit impulse input. This feature of h(t) means that if the response of a linear time-invariant system to the unit impulse input is known, then convolution can be used to compute the response to any input signal. Of course, you cannot sketch a unit impulse for x(t), but you can approximate an impulse by a tall, thin pulse. The area of the approximate impulse will not be 1 because of the limited window size. Therefore, the output signal will be an approximation to h(t) that is scaled by a small constant.

You can pause the audio while working on the exercises.

For the second exercise, recall that a causal system is a system with the property that the output signal at time t depends only on input signal values for times less than or equal to t. By trying some examples, you should verify with the applet that a causal system corresponds to an impulse response h(t) that is zero for negative values of t. In other words, a causal system corresponds to a one-sided impulse response.

Next, consider the effect of interchanging h(t) and x(t). It should be readily apparent that the output of a system with the impulse response x(t) and input h(t) is the same as the output of a system with the impulse response h(t) and input x(t). In other words, convolution is a commutative operation.

The fourth exercise is to describe the relationship between a system with impulse response h(t) and a system with impulse response h(t − T), where T is a constant.

Exercise 5 involves understanding how a linear time-invariant system can act as a low-pass filter. Select the decaying exponential for h(t), or draw something similar. Then sketch input signals that oscillate rapidly and perform the convolutions. Notice that the output signals have smaller amplitude and oscillate less than the input signals. The system filters out some of the high-frequency content in the input signal.

The last exercise is to sketch a simple unit impulse response so that the system acts as a high-pass filter. You probably will find this very difficult to do, and you may want to consider this as motivation for further study of frequency-selective filtering.

Quiz on Continuous-Time Convolution

A companion to Joy of Convolution. It is recommended that you use the applet to explore the question, and then see if you can mathematically justify your conclusion.

  1. If the unit-impulse response of an LTI system and the input signal both are rectangular pulses, then the output will be a
    • rectangular pulse
    • triangular pulse
    • ramp function
    • none of the above
  2. If h(t) is a unit-step function and x(t) is a unit-ramp function, then the output y(t) will be a
    • step function
    • ramp function
    • triangular pulse
    • quadratic function
  3. If an input signal is applied to two LTI systems with respective unit-impulse responses h(t) and 3h(t − 2), then the response of the second system is the response of the first
    • amplitude scaled by 3 and delayed by 2
    • amplitude scaled by 3 and advanced by 2
    • amplitude scaled by 3
    • none of the above
  4. If h(t) = 2 sin(ωt) u(t), where u(t) is the unit-step function and ω is large, then the behavior of the system is such that
    • low frequency input signals are attenuated
    • low frequency input signals are amplified
    • high frequency signals are amplified
    • the response to a unit-step input is identically zero
  5. If x(t) = h(−t), then
    • y(t) = 2h(t)
    • y(t) = y(−t)
    • y(t) = −y(−t)
    • the largest value of y(t) occurs at t = 0
